# Code of Conduct

I am committed to fostering a respectful, harassment-free community. Be constructive, assume good intent, respect differing experience levels, and keep discussion focused on the work.

Harassment, discrimination, intimidation, or sharing another person's private information without permission is not acceptable. Report concerns privately to the repository owner. Protein Lab is a passion project and as such, I will try to handle all reports promptly. However, because this is not my main job, I may not be able to get to some reports in a reasonable time frame. 

This Code of Conduct applies in project spaces and when representing Protein Lab publicly.
