# Code of Conduct

We are committed to a respectful, harassment-free community. Be constructive, assume good intent, respect differing experience levels, and keep discussion focused on the work.

Harassment, discrimination, intimidation, or sharing another person's private information without permission is not acceptable. Report concerns privately to the repository owner. Reports will be handled promptly and as confidentially as practical.

This Code of Conduct applies in project spaces and when representing Protein Lab publicly.
