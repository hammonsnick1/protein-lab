# Security policy

## Reporting a vulnerability

Do not file a public issue for a suspected security vulnerability or exposed secret. Use GitHub's private vulnerability reporting for this repository, or contact the repository owner privately with a minimal reproduction and impact summary.

Please do not include credentials, personal project data, or exploit payloads in a report. We will acknowledge reports, investigate, and coordinate a fix before public disclosure.

## Supported versions

Security fixes are made on the current `main` branch and current release line. Older builds may not receive fixes.
